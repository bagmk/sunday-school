# 주일학교 게임 · Sunday School Games

중고등부 수업에서 TV나 프로젝터 한 대로 함께 하는 성경 게임 모음이에요. 첫 화면은 앱 목록이고, 앱을 누르면 바로 게임이 열려요.

A small "app store" of Bible games for a youth Sunday-school class, played together on one screen.

- **열기 · Open:** https://bagmk.github.io/sunday-school/
- **오프라인:** 폴더의 `index.html`을 더블클릭하면 인터넷 없이 앱 목록이 열려요. 각 게임도 파일로 바로 열 수 있어요.

## 새벽 3시 · The Fourth Watch — 진행 (선생님용)

- 노트북을 프로젝터에 연결하고 게임을 열어 `Enter`로 시작해요. 학생 4–5명이 한 사람씩 60초 동안 하고, 선생님이 마지막에 해요.
- 시간이 끝나면 「다음 사람」 화면이 나오고, `Enter`를 누르면 다음 사람이 바로 시작해요.
- 선생님 전용 키 (화면에는 안내가 나오지 않아요):

| 키 | 기능 |
| --- | --- |
| `Enter` | 시작 · 계속 |
| `N` | 다음 사람으로 넘기기 |
| `D` | 리허설용 디버그 화면 켜기/끄기 (다음 사람으로 넘어가거나 `Esc`로 첫 화면에 가면 자동으로 꺼져요) |
| `M` | 소리 끄기/켜기 |
| `Esc` | 첫 화면 |
| `+` / `-` | 말씀 간격 ±1초 (8–12초, 다다음 말씀부터 적용) |
| `1` / `2` / `3` | 난이도 쉬움 / 보통 / 어려움 (바람 빠르기는 다음 사람부터) |

- 게임에 숨겨진 규칙은 수업 전에 `D` 화면을 켜고 직접 연습해 보세요. 학생들에게는 미리 말하지 않아요.

- 약 10초마다 예수님 옆에 「오라 · Come」 말풍선이 2.5초 동안 조용히 떠요.
- **정답:** 바람은 늘 같은 방향, 같은 속도로 흘러요. 그런데 말풍선이 뜰 때에 맞춰 배 앞머리에서 예수님까지 곧장 이어지는 **가운데 줄**(물에 비친 예수님 빛이 있는 줄)에 바람 사이 틈이 생겨요. 그때 **배 앞머리에서 나와**(마 14:29) ↑를 탁탁탁 **멈추지 않고 곧장 올라가면** 틈을 지나고, 맨 위에서 한 번 더 누를 때 예수님께 닿아요.
  - 말풍선이 떠 있는 동안 언제 출발해도 되고, 1초에 세 번 이상 누르면 돼요. 더 빨리 눌러도 베드로는 한 칸에 0.3초씩 일정하게 걸어가요. 일단 출발하면 말풍선이 사라져도 계속 갈 수 있어요.
  - 휴대폰은 탭(또는 위로 스와이프)을 멈추지 않고 이어 가요.
- 멈추거나(0.5초 넘게) 옆·아래로 가면 '바람을 본 것'이에요. 보통 곧바로 바람이 몰려와 빠져요(14:30).
- 이미 바다에 나가 있거나, 배 앞머리가 아닌 곳에서 나서거나, 말풍선이 없을 때는 아무리 빨리 올라가도 맨 위 줄을 넘을 수 없어요. 바다에 나가 있다면 ↓로 배에 돌아와 기다리면 돼요. 말풍선이 뜰 때 물에 빠지는 중이었다면 그번 「오라」는 지나가요.
- **치트키:** 말풍선이 떠 있을 때 ↑를 새로 눌러 떼지 않고 계속 누르고 있으면(휴대폰: 화면을 꾹 누르고 있기), 베드로가 혼자 빛나며 물 위를 걸어가요. 어느 줄에서든 되고, 바람이 닿지 않아요. 손을 떼면 빠져요.

### 휴대폰 버전 · 스와이프

- 앱 목록의 「휴대폰 · Phone」 버튼이나 `apps/fourth-watch/mobile.html`로 열어요. 휴대폰에서 카드를 누르면 자동으로 휴대폰 버전이 열려요.
- 조작: 탭 = 위로 한 칸, 스와이프 = 그 방향으로 한 칸. 위로 스와이프한 뒤 손가락을 떼지 않으면 ↑를 누르고 있는 것과 같고, 떼면 키를 뗀 것과 같아요. 손가락을 가만히 대고만 있으면 아무 일도 없다가 뗄 때 한 칸 올라가요(「오라」 말풍선이 떠 있을 때 새로 꾹 누르고 있는 것만 ↑를 누르고 있는 것으로 쳐요).
- 두 엄지로 번갈아 탭해도 돼요. 화면에 마지막으로 닿은 손가락으로 움직여요.
- 시간이 끝나면 「시간 종료」가 2초 동안 나오고, 「다음 사람」 화면은 1초 뒤부터 탭을 받아요. 계속 탭하던 손가락 때문에 다음 차례가 저절로 시작되지 않아요.
- 휴대폰을 가로로 돌리면 게임이 멈추고 세로로 돌려 달라는 안내가 나와요.
- 게임 중에 화면 가장자리를 밀어 '뒤로 가기'가 되면 한 번은 무시돼요. 나가려면 2초 안에 한 번 더 하거나 「다음 사람」 화면에서 뒤로 가세요.
- 오른쪽 위 스피커 버튼으로 소리를 끄고 켜요. 아이폰은 무음 모드(옆면 스위치나 제어 센터의 종 모양)를 끄고 볼륨을 올려야 소리가 나요. 게임의 스피커 버튼으로는 무음 모드를 알 수 없어요.
- 키보드 버전도 터치 화면(태블릿, 터치 노트북)에서는 같은 스와이프로 움직일 수 있어요. 키보드가 없는 태블릿에서는 첫 터치 뒤 화면 안내도 탭·스와이프로 바뀌어요.

### 소리

- 바람 소리를 부드러운 파도 소리로 바꿨어요 (고음 쉭쉭거림 제거, 물에 빠질 때 '딱' 소리 제거). 휴대폰 스피커에서도 들리도록 음량과 음색을 맞췄어요. 소리는 모두 브라우저에서 만들어지고, 오디오 파일은 없어요.
