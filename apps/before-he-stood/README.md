# 그가 일어나기 전 · Before He Stood

마태복음 9:1–8을 세 사람의 눈으로 따라가는 한영 이야기 게임이에요. 중고등부 수업에서 TV 한 대로 반 전체가 세 인물을 차례로 함께 해요.

A bilingual (Korean/English) story game on Matthew 9:1–8. A youth class plays all three characters together on one TV.

- **플레이:** https://bagmk.github.io/sunday-school/apps/before-he-stood/ (앱 목록: https://bagmk.github.io/sunday-school/)
- **오프라인:** 폴더의 `index.html`을 더블클릭하면 인터넷 없이 실행돼요. 파일 하나로 공유하려면 `dist/before-he-stood.html`을 보내면 돼요.

## 어떤 게임인가요

| 인물 | 이야기 |
| --- | --- |
| 서기관 므나헴 | 아침에 시편을 읽은 서기관이 그날 바닷가에서 그 말씀을 다시 만나요 |
| 친구 요나 | 네 해째 누워 지내는 친구를 침상째 들고 예수님께 가요 |
| 침상의 아셀 | 침상에 누운 채 실려 가서, 처음 듣는 말을 들어요 |

- 인물마다 **엔딩은 하나**예요. 끝까지 가면 그 인물의 암송 구절이 나오고 이야기가 끝나요.
- 엉뚱한 선택을 하면 짧고 웃긴 장면 뒤에 **「싹둑! 여기서 이야기가 끊겼어요」**가 나와요. 「다시 고르기」를 누르면 그 선택으로 돌아가요.
- 어떤 보기는 친구나 제자가 「그건 아니지!」 하고 막아서 **사라져요**. 남은 보기에서 다시 골라요.
- 끝나면 **이야기 나무**가 나와요. 그날 잘려 나간 가지들이 보이고, 아직 못 본 가지는 흐리게 자리만 보여요.
- 예수님의 말씀은 개역개정과 ESV 본문 그대로만 나와요. 얼굴은 그리지 않고 빛으로만 보여요.

## TV로 함께 할 때

- 컴퓨터에서 주소를 열고 `F`(또는 오른쪽 위 전체 화면 버튼)로 전체 화면을 켜요. 언어는 「함께」를 고르면 한국어와 영어가 같이 나와요.
- 다음으로: `Space` · `Enter` · `→` · `↓` · `PageDown` (프레젠테이션 리모컨도 돼요)
- 보기 고르기: 화살표로 옮기고 `Enter`, 또는 `1`–`4`
- 리모컨으로 고르기: 다음/이전 버튼으로 보기 사이를 옮기고, **다음 버튼을 1초쯤 꾹 누르면** 그 보기를 골라요. 리모컨의 화면 끄기 버튼(`B` 또는 `.`)을 눌러도 골라져요. 새 선택지에서 처음 누르는 버튼은 첫 보기에 테두리만 보여 줘요.
- 브라우저: 크롬, 엣지, 사파리(15.4 이상)에서 돼요.
- 메뉴: `Esc`
- **순서:** 서기관 → 친구 → 아셀. 서기관의 속생각이 다른 두 이야기에서 대답으로 돌아오고, 아셀이 일어나는 장면이 마지막에 와요.
- **시간:** 인물 하나를 끝까지 하면 소리 내어 읽기로 5분쯤이에요. 잘린 가지를 한두 번 보면 1–2분이 더 들어요. 「함께」에서도 소리 내어 읽는 건 한 언어만 하면 세 인물이 20분 안에 끝나요.
- 폰에서도 세로 화면으로 할 수 있어요.

## 폴더 구조

```
index.html            게임
data/                 이야기와 본문 (여기만 고치면 내용이 바뀌어요)
  meta.js             제목과 인물 카드
  characters.js       인물 이름과 색
  scripture.js        성경 본문 (개역개정, ESV)
  common.js           프롤로그, 인물 선택 화면 문장
  routes/*.js         세 인물의 이야기
js/, css/             엔진, 화면, 그림
docs/                 설계 문서
tools/                검사, 단일 파일 빌드, 자동 플레이 검사 도구
dist/                 파일 하나로 된 게임
```

## 내용을 고치려면

- 이야기는 `data/routes/*.js`에서 고쳐요. 모든 문장이 `{ ko: "...", en: "..." }` 형태예요.
- 보기에는 세 종류가 있어요: 그냥 이어지는 보기, `bad: "아이디"`(이야기가 잘리는 가지), `scold: { ... }`(꾸중 듣고 사라지는 보기).
- 성경 구절은 문장에 직접 쓰지 않고 `{{v:KEY}}` 토큰이나 구절 장면으로 불러와요. 본문은 `data/scripture.js` 한 곳에만 있어요.
- 고친 뒤 검사: `node tools/validate.mjs`
- 단일 파일 다시 만들기: `node tools/build-single.mjs` (고친 뒤 올리기 전에 꼭 실행해요. `index.html`의 캐시 번호도 같이 바뀌어서, TV 브라우저가 예전 파일을 섞어 쓰지 않아요)
- 자동 플레이 검사(선택): `node tools/playtest.mjs` (Playwright 필요)
